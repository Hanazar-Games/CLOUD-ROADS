# CLOUD ROADS

原创浏览器无限山地驾驶与探索引擎。包含确定性地形、分块流式加载、LOD、浮动原点、盘山折返路线、桥隧、植被、云海和昼夜天气。可驾驶原创敞篷车，也可切换开发者相机自由探索。

当前开发版 **v0.1.10**。山坡树林更丰富，重做低多边形树木，加入林缘草丛、碎石、远景树冠和山体细节。支持四轮悬挂、三种驾驶视角、森林、沙漠、双幅高速、服务区及天气时段选择。高山路线反复上山、过垭口、下山，可自选约 1.5–4 公里视距。页面右上角「公告」可查看当前版本及历史公告；仓库记录见 [更新公告](CHANGELOG.md) 和 [开发记录](docs/development.md)。音效与背景音乐尚未实现。

在线体验：[CLOUD ROADS](https://hanazar-games.github.io/CLOUD-ROADS/)。GitHub Actions 在 main 更新后检查并部署 `dist`；Pages 使用 GitHub Actions 发布方式。

## 运行

需要 Node.js 22.12+、npm，以及支持 WebGL2 的桌面浏览器。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生产版本使用 `npm run build`，然后 `npm run preview`。不需要账户、API key 或外部美术资源。

## 操作

点击右上角「开始驾驶」，车辆出现在附近道路右侧，面板自动收起。W 加速，S 刹车至停后倒车，A / D 转向，Space 手刹，C 切换跟车／驾驶舱／引擎盖，R 回到最近安全道路并驻车。仪表显示 km/h、P / N / D / R 行驶状态和本次行程，R 回正保留行程，重新上车清零。P 暂停，F3 调试。

展开面板可选柔软／标准／运动悬挂、50–90° 视野及 5–11 m 跟车距离。拖动观察或双击锁定鼠标，按 Esc 释放；「视角回正」恢复正前方。调整设置时车辆冻结，点击画面并重新按键继续。雨天抓地降低，夜间及隧道自动开灯，隧道前自动缩近跟车视角。

车辆采用轻量四轮弹簧与平面转向模型，支持道路、桥面、服务区地坪与匝道接触，以及简化护栏阻挡；没有完整刚体翻滚或建筑、树木碰撞。当前支持桌面键盘操作，没有移动触屏或手柄驾驶。所有车模与 UI 在项目内原创实现。

「退出驾驶」保留当前位置并切回自由相机。点击景观定位、返回起点或更换世界也会退出驾驶，重新点击「开始驾驶」可在新位置附近上车。自由探索的操作如下：

| 操作 | 按键 |
| --- | --- |
| 飞行 | W / A / S / D |
| 上升 / 下降 | Space / Shift |
| 四倍加速 | Ctrl |
| 观察 | 按住鼠标左键拖动 |
| 锁定 / 释放鼠标 | 双击画面 / Esc |
| 暂停飞行、云与雨 | P |
| 调试面板 | F3 |

左侧可修改种子、调整飞行速度（20–1200 m/s）、返回起点和切换地形线框。默认种子为 `CLOUD-ROAD-001`。自由相机不受碰撞约束，可穿过地形。

「地貌与道路」可选择高山雪岭、森林山谷、沙丘旷野或沙漠峡谷；道路可选山路或双向四车道高速。6 / 8 / 10 米表示单幅沥青宽度，不含路肩，高速为每个方向各一幅，中央分隔带宽 4 米。点击「应用并返回起点」重新生成当前种子的世界，保留光照、云层及植被开关。森林混合松树、阔叶树、林下灌木与草丛，岩坡散布碎石，干旱地貌有仙人掌与矮灌丛；「植被」可控制显示。

「下一服务区」定位并俯瞰下一处停车与补给场地。服务区按道路里程约每 10–20 公里生成，高速两侧各有连接匝道。定位期间可继续探索，暂停或公告会暂停定位，返回起点可取消。场内有停车位、景观车、坡屋顶休息建筑、廊架、种植池、充电桩、补给棚与照明；可从道路驾驶进入，景观车辆与设施没有充电、加油或休息交互。

「渲染距离」可选约 1.5 / 2 / 3 / 4 公里，即时生效、保留位置，换种子或地貌也保留选择。较远视距需要更多加载时间与显存，近处地形和植被优先保留细节，天气和云层仍会限制实际能见度。

高山雪岭路线从低缓山谷爬升，经过两侧山脊之间的垭口后下降，再进入下一片山地。「下一垭口」可定位前方的山口，旁边显示当前路线阶段；定位支持暂停、公告暂停和返回起点取消。其他地貌不提供此入口。

「天气与时间」提供晴天、多云、雨天和浓雾，时段可选清晨、午后、金色时刻、橙色晚霞和夜晚，默认金色时刻。「光照时刻」支持 07:00–22:00 连续微调；「望向太阳／月亮」调整朝向并继续探索，「山体投影」控制附近地形与桥梁的阴影。天气与时间即时生效，换种子保留选择，没有自动昼夜循环。云层开关不取消天气雾。

「隧道入口」移到附近洞口前方，调低速度后按 W 前进并用鼠标跟随道路弯曲。山路为单洞，高速为双洞；进入洞内后雨线和云雾减弱，保留内部照明。没有符合条件的隧道时按钮暂不可用。「灯光路段」移到分段布置的路灯旁，选择夜晚可观察照明；「路灯」开关只控制室外灯具。F3 显示隧道数、遮蔽程度与附近亮灯数。

控制面板在矮窗口内可滚动，也可用右上角按钮收起。按钮获得焦点时仍可使用 P 暂停和 F3 调试，编辑输入框和阅读公告时不拦截这些按键。暂停、编辑种子、打开公告或窗口失焦会清除旧按键状态，恢复后需重新按下移动键。公告和调试面板的关闭按钮在滚动内容时保持可见。

地形或图形故障期间，探索控件暂不可用，相机与云漂移停止；公告仍可查看。地形故障可「重试当前世界」，保留光照和显示设置；图形上下文恢复后自动重新启用操作。3D 启动失败时提供页面重新加载入口。

点击「道路视角」移动到水平距离最近的路段上方；「发卡弯视角」俯瞰折返弯，「桥梁视角」从侧面观察已生成的高架桥，观察位置会避开地面。「路线骨架」默认关闭，开启后显示可穿透地形的中心线和控制点。F3 可查看道路里程、坡度、曲率、驻留路段、发卡弯、桥梁与支撑数量，以及相机下方地面的生物群系、海拔、坡度、积雪比例、雪线和程序化温湿度。F3 地面数据与坐标一起采样，底部海拔仍表示相机高度。

点击「穿云起点」进入附近安全的低谷，按住 Space 上升，穿过浓雾后拖动视角俯瞰云海；Shift 可下降返回。「云层」控制显示，F3 可查看云下／云中／云上、当地云顶与雾的范围。附近没有足够低的谷地时会提示重试，不会把相机放进山体。穿云入口自动开启云层，普通换种子保留开关设置。

## 验证

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:pages
```

端到端测试自动构建并启动生产预览，使用独立的 `127.0.0.1:4318` 端口。覆盖东西／南北方向各 30 公里实际飞行、道路增量生成与回放、种子切换、原点重定位、资源回收、暂停和输入失焦。单元测试另覆盖 10 / 30 / 100 公里的地形与道路非渲染模拟、跨 LOD 接缝，以及真实路面／地形三角形的射线间距检查。

启动开发服务器后可测量 1080p 连续飞行性能：

```sh
npm run benchmark
# 标准视距 / 4 km 视距连续驾驶
npm run benchmark -- --drive
npm run benchmark -- --drive --far
# 可指定已运行的开发服务器或生产预览地址
npm run benchmark -- http://127.0.0.1:4173
```

报告包含 GPU 名称、实际画布分辨率、帧率、帧间隔和超过 50 ms 的主线程任务。macOS 测试使用 Metal，其他平台由 Chromium 选择渲染后端；软件渲染的测量不能代表硬件加速性能。

## 实现

- TypeScript、Vite、Three.js / WebGL2，原生 HTML 控件。
- 确定性 PRNG、坐标哈希梯度噪声、分形山体、山脊和 domain warp。
- 256 m 分块：5×5 高精度（64 格）、9×9 中精度环（16 格），外层为低精度（8 格）；按视距保留 169 / 289 / 625 / 1089 个活动分块，道路附近额外提升至 64 格。
- 各级 LOD 共用 4 m 边界节点与连接，保持几何和着色属性连续；远处分块保留粗网格内部。
- 1–4 个 Worker 根据局部道路走廊快照计算耦合后的高度、法线和颜色，使用 transferable buffers 回传；主线程每帧最多应用两个结果，并设置约 2 ms 的开始处理预算。
- 生物群系按地貌、海拔、坡度及种子温湿度噪声混合山谷、森林、岩石、高山、雪区与沙漠颜色。各地貌有不同高度函数，岩层颜色随高度起伏，跨分块和 LOD 的属性保持一致。
- Worker 按实际地形三角形生成树木、灌木、草丛和碎石，覆盖分块边界并避开陡坡、雪区、道路和设施。近树、地被与远景树冠共用九个实例批次；远景按全局候选单元固定抽稀，随所选视距加载与回收，使用局部缓冲更新和浮动原点移动。
- 山体材质以世界坐标叠加程序化草地与岩面细节，细颗粒随屏幕覆盖范围衰减，不使用外部纹理；山体几何保留低多边形风格。
- 共享材质，按 LOD 复用 Mesh、Geometry 和 GPU 属性缓冲；卸载分块返回有界池。仅池溢出、换种子或销毁世界时释放资源。
- 相机水平距离超过 5 km 后重定位渲染坐标，逻辑坐标保持不变。
- 云场由种子生成一张 128×128 周期纹理，云底 1800 m、云顶在约 2300 m 附近起伏。八层云在一次全屏合成中按场景深度遮挡，与相机高度雾配合完成穿云；使用逻辑坐标和有界风偏移，兼容浮动原点。场景颜色只在最终输出时做色调映射，渲染目标和云纹理复用。
- 太阳方向、暖光、天空渐变、远景薄雾和云层着色共用光照状态；天空与雾在现有全屏合成中计算。近中景地形、道路与桥梁投射 2048² 局部阴影，按逻辑世界的灯光空间对齐阴影网格，保持原点重定位前后稳定。
- 近处分块优先，并按相机朝向加权；过期生成结果不会加入新区域。
- 高山地形沿南北投影每约 32 km 生成一组独立种子山地，谷底、垭口位置和高度变化，边界高度与坡度连续。谷地两侧低缓，垭口两侧山脊更高；参数缓存有界，任意远处可确定性重建。
- 普通道路候选评分结合地形落差、悬崖代价、坡度、曲率和种子引导，高山路线额外追踪谷线与垭口走势；积分平滑变化的方向与坡度，保持路段接缝的位置、切线与曲率连续，横坡随曲率变化。
- 陡峭区域按地形高差选择爬升或下降，生成成对的 150° 折返弯；弯心最小半径约 36.7 m，弯间至少 384 m，组间至少 4 km。坡度限制为 ±6%，普通弯道半径大于 100 m。
- 道路总体沿北向走廊推进，保持中心线不自交。二维空间索引用于最近路段定位及 Worker 走廊裁剪，支持反向或不连续的局部道路片段。
- 路基宽度随车行道配置变化，跟随道路高度和横坡，向外平滑切坡或填方。高速采用独立双幅路面、中央分隔和护栏，坡度限制为 ±4%，不生成发卡弯。桥跨内部取消填方，桥头用 32 m 过渡段衔接路基。
- 道路高于谷底 40 m 的连续距离达到 80 m，且能在 1400 m 内找到两端落点、桥侧没有山体侵入时，生成混凝土高架桥。桥面、每约 32 m 的桥墩、桥台、基础及纵梁／扶手使用三个实例批次。超出检测范围的深谷暂时保留填方。
- 天然地面高于全幅道路 11 m 且曲率适宜时检测隧道，保留路基地形并添加拱形衬砌和覆盖网格，洞口真实留空；高速按两幅道路分别扫掠。覆盖区排除原地形植被，避免树干穿出结构。
- 道路护栏、灯杆与灯头使用共享实例批次，按逻辑里程分段布灯。固定四个无阴影点光源只照亮相机附近路灯或隧道灯；几何版本变化时更新，原点移动只平移批次。雨线在天空合成后绘制，并读取场景深度实现遮挡。
- 服务区以 15 km 周期加入种子偏移，完整窗口内评分选址，使相邻间距保持 10–20 km。停车场与匝道地形传入 Worker，匝道保留主路横坡后平滑过渡到场地；服务区范围排除桥隧。模型和标牌使用共享实例批次及原创像素字形图集，服务区照明复用附近四灯池。
- 道路窗口前后各预留至少 4000 m（南北投影），最远视距扩到 5952 m，涵盖地形窗口和结构检测范围；覆盖就绪后才调度地形，后退时也会补齐覆盖。最多保留 256 个路段，每段 96 m（发卡弯 144 m）、48 个采样间隔；中心线和路面共用缓存。路面使用一个复用网格和原创 GLSL 沥青／标线材质；所有标线按道路里程连续排列。

当前不保存玩家状态。后续保存功能只应写入浏览器存储，不应写入仓库或构建产物。

详细阶段结果和限制见 [开发记录](docs/development.md)。Scenic Director 的沿途体验编排仍待完成；本版按用户要求先接入驾驶。
