# CLOUD ROADS

原创浏览器无限山地探索引擎。当前完成 **Phase 0–4**：确定性无限地形、分块流式加载、LOD、浮动原点、无限道路骨架与路面网格，以及道路地形耦合。当前可用开发者相机探索；车辆尚未实现。

## 运行

需要 Node.js 22.12+、npm，以及支持 WebGL2 的桌面浏览器。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生产版本使用 `npm run build`，然后 `npm run preview`。不需要账户、API key 或外部美术资源。

## 操作

| 操作 | 按键 |
| --- | --- |
| 飞行 | W / A / S / D |
| 上升 / 下降 | Space / Shift |
| 四倍加速 | Ctrl |
| 观察 | 按住鼠标左键拖动 |
| 锁定 / 释放鼠标 | 双击画面 / Esc |
| 暂停飞行 | P |
| 调试面板 | F3 |

左侧可修改种子、调整速度（20–1200 m/s）、返回起点和切换地形线框。默认种子为 `CLOUD-ROAD-001`。当前为无碰撞开发者相机，可穿过地形。

点击「道路视角」移动到当前南北坐标对应的路段上方；「路线骨架」显示可穿透地形的中心线和控制点，便于检查路线。F3 可查看道路里程、坡度、曲率和驻留路段数。

## 验证

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

端到端测试自动构建并启动生产预览，使用独立的 `127.0.0.1:4318` 端口。覆盖东西／南北方向各 30 公里实际飞行、道路增量生成与回放、种子切换、原点重定位、资源回收、暂停和输入失焦。单元测试另覆盖 10 / 30 / 100 公里的地形与道路非渲染模拟、跨 LOD 接缝，以及真实路面／地形三角形的射线间距检查。

启动开发服务器后可测量 1080p 连续飞行性能：

```sh
npm run benchmark
# 可指定已运行的开发服务器或生产预览地址
npm run benchmark -- http://127.0.0.1:4173
```

报告包含 GPU 名称、实际画布分辨率、帧率、帧间隔和超过 50 ms 的主线程任务。macOS 测试使用 Metal，其他平台由 Chromium 选择渲染后端；软件渲染的测量不能代表硬件加速性能。

## 实现

- TypeScript、Vite、Three.js / WebGL2，原生 HTML 控件。
- 确定性 PRNG、坐标哈希梯度噪声、分形山体、山脊和 domain warp。
- 256 m 分块：5×5 高精度（64 格）、9×9 中精度环（16 格）、17×17 远景环（8 格），共 289 个活动分块；道路附近额外提升至 64 格。
- 各级 LOD 共用 4 m 边界节点与连接，保持几何和着色属性连续；远处分块保留粗网格内部。
- 1–4 个 Worker 根据局部道路走廊快照计算耦合后的高度、法线和颜色，使用 transferable buffers 回传；主线程每帧最多应用两个结果，并设置约 2 ms 的开始处理预算。
- 共享材质，按 LOD 复用 Mesh、Geometry 和 GPU 属性缓冲；卸载分块返回有界池。仅池溢出、换种子或销毁世界时释放资源。
- 相机水平距离超过 5 km 后重定位渲染坐标，逻辑坐标保持不变。
- 近处分块优先，并按相机朝向加权；过期生成结果不会加入新区域。
- 道路候选评分结合地形落差、悬崖代价、坡度、曲率和种子引导；三次 Hermite 样条直接约束端点方向与坡度，避免自动插值产生急弯。
- 道路目前在向北的前进走廊内生成，防止自交；目标坡度为 ±6%，测试上限为 10%，普通弯道半径测试下限为 100 m。发卡弯属于下一阶段。
- 中心线两侧 12 m 路基跟随道路高度和横坡，向外平滑切坡或填方，保留走廊外自然地形。深峡谷目前仍采用填方，桥梁检测尚未实现。
- 道路窗口前后各预留约 2600 m（南北投影），覆盖就绪后才调度地形。最多保留 96 个约 96 m 的路段，中心线和路面共用采样缓存。路面使用一个复用网格和原创 GLSL 沥青／标线材质；所有标线按道路里程连续排列。

当前不保存玩家状态。后续保存功能只应写入浏览器存储，不应写入仓库或构建产物。
