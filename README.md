# CLOUD ROADS

原创浏览器无限山地驾驶与探索引擎。包含确定性地形、分块流式加载、LOD、浮动原点、盘山折返路线、桥隧、植被、云海和昼夜天气。可驾驶原创敞篷车、第一人称步行跑跳，也可切换开发者相机自由探索。

当前开发版 **v0.1.57**。连续穿山隧道取消长度和曲率限制，修复隧道上方山体凹陷，增加公里标牌、洞口加密照明、侧壁引导与车道信号。现有 38 种载具、12 种地貌，支持燃油 / EV、四向互通、服务区、地下车库、NPC 与自动驾驶。公告见 [更新公告](CHANGELOG.md)，实现与限制见 [开发记录](docs/development.md)。

在线体验：[CLOUD ROADS](https://hanazar-games.github.io/CLOUD-ROADS/)。GitHub Actions 在 main 更新后检查并部署 `dist`；Pages 使用 GitHub Actions 发布方式。

## 运行

需要 Node.js 22.12+、npm，以及支持 WebGL2 的桌面浏览器。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生产版本使用 `npm run build`，然后 `npm run preview`。不需要账户、API key 或外部美术资源。

## 操作

「世界与道路 → 贴山选线与地标大桥」提供贴山程度 0–100%、普通桥目标高度 20–1000 m；目标是选线偏好，仍遵守坡度和海拔约束。默认每约 100–200 km 安排双塔直线水平斜拉桥，可选间隔 50–300 km、长度 800–2000 m、净空 20–300 m；桥区避让服务区和岔路，地形或零坡度无法衔接时会继续寻找。「探索工具 → 下一座超级斜拉桥」支持定位与取消。

设置顶部可按参数名或选项搜索，Enter 直达首项、向下键选择结果。燃油转速响应可调 50–150%，数值越高跟随越快；松油门降低负载，但带挡高速滑行不会立即降到怠速。换挡有短暂扭矩衔接，仪表显示转速条与当前负载，音色同步变化。声音设置提供独立碰撞音量及驾驶时音乐压低 0–80%，并随格式 9 预设保存。

「世界与道路」新增月球、火星：环形山与月海、赤色台地与峡谷，均按世界种子连续生成；对应黑色或尘色天空，火星落日偏蓝。关闭地球云雨雪和天然植物，仅保留岩块；地球天气与季节偏好在返回后恢复。车辆重力分别为 1.62、3.71 m/s²，步行按相同比例降低游戏重力，低重力刹车更慢、跳跃更高。场景是可驾驶的科幻公路，非航天科学模拟。

「动力类型」选择燃油或 EV，默认燃油；驾驶时 `Shift+I` 可切换，保留车速、位置与里程。EV 单速驱动，无燃油怠速和换挡声，`Shift+N` 调节回收 0–3 档；回收只在上电、接地且松电门时生效，受湿滑和低重力抓地限制，仪表同步显示。无电量、油量或续航消耗。主动换车型保留动力选择，接管停放车辆沿用该车动力，可随时再切换。

三节公路列车每节货厢 10 米，含牵引车、连接间距总长 39.4 米；72 吨、850 kW，三处连接分别转动，制动和坡道响应计入挂车。`Y` 联动尾门、`Shift+H` 开关挂车独立制动，开门前需停稳。推荐宽路缓弯，现有车库车位和 NPC 不自动生成此车型；保持运动学铰接近似，没有多刚体碰撞或脱挂。

行驶中 A / D 转向并长按 Space 手刹漂移，松手并反打方向恢复抓地。持续拉手刹会减速直至停下，长车更慢进入侧滑。设置「驾驶与视角 → 漂移与抓地力」提供抓地力 25–150%（越低越滑）、手刹强度 40–100%、反打辅助 0–100%（0% 完全手动）及独立重置。默认分别为 100%、100%、60%，随玩家换车保留，抓地力叠加雨雪与路外效果。格式 9 预设包含这些参数；旧预设需重新配置保存，原浏览器数据不覆盖。漂移仍为平面物理近似，没有轮胎温度、磨损、胎烟或胎痕。

F 上下车时先等待车门打开，进入或离开后自动关门；关门期间可点火，关好后才能起步。客车使用右侧乘客门，摩托车没有车门动画。设置、暂停和失焦冻结待完成动作，换车或离开当前模式取消旧流程。

点击「开始步行」进入附近道路的第一人称视角。WASD 行走（2.2 m/s），按住 Shift 跑步（4.8 m/s）、E 疾跑（8 m/s），Space 跳跃，R 回到道路。拖动鼠标或双击锁定观察，斜杠 / 或 Pause 暂停；落地后松开再按才能再次起跳。平缓道路的护栏缺口允许走进山野，桥下不会吸附桥面。步行采用简化地面、桥底、隧道、护栏及服务区主要建筑和停车车辆碰撞，没有人物全身模型、树木或桥墩实体碰撞。服务区俯瞰视角下开始步行会落在场地入口。

点击右上角「开始驾驶」，车辆出现在附近道路右侧，面板自动收起。·（Backquote） 点火后 W 加速，S 刹车至停后倒车，A / D 转向，Space 手刹，C 切换跟车／驾驶舱／引擎盖，R 回到最近安全道路并驻车。先停稳，再按 F 在驾驶室旁安全位置下车并驻车，靠近可到达的入口后 F 开门上车，也可点击「回到车辆」；检查桥面、护栏、头部空间和车身离地高度，腾空或空间不足时不能下车。仪表显示 km/h、P / N / D / R 行驶状态和本次行程，R 回正、F 上下车与「回到车辆」保留行程。远离停车位置时按钮改为「重新放置车辆」，点击会在附近道路放车并清零行程。斜杠 / 或 Pause 暂停，反斜杠 调试。

「NPC 交通」可选正常通行、缓慢车流、走走停停和排队拥堵，车队逐步形成，切回正常通行解除排队。可调密度 0–100%，默认 35%，另设附近数量上限 12–120 辆，默认 24 辆。目标数量为上限乘密度，0% 关闭交通，按安全车距逐步补充；窄路可能低于目标，高数量增加 CPU 负载。二十二种道路车型与十种车漆按种子生成，按实际车道宽度筛选车型；车辆跟车、弯前减速，同向有多车道时可提前打灯、检查前后间隙并平滑变道，安全时回到右侧。急弯、隧道、路口与行人附近不主动变道，不含完整路口优先权或跨路线导航。停车后靠近驾驶室按 F 开门上车，可接管停稳的 NPC。低引擎盖、车顶和货台可承托步行玩家；先跳上较低部位，再跳向车顶。高车不能从地面直接跳到顶。

「地下停车场」可定位地面入口或 B1–B5，每层 33 个车位、层高 6 米，矩形楼层通过并排直线折返坡道连接，最大坡度约 11%。独立车库有主路入口匝道；部分服务区另有接通地面停车区的 B1–B3 车库。设置可选择「逐层加载 · 预加载相邻层」或「全部楼层加载」，后者增加内存与绘制量；基础楼板与外墙持续保留。照明亮度 50–180%，提供顶灯、坡道引导灯和有界局部补光，地下遮蔽雨雪。占用率 0–100%、随机或指定车型及随机车色可调；大车只进入加长车位。选择本层车辆后点击「走到所选车辆旁」，按 F 开门上车、·（Backquote）点火。附近服务区加载后可选择车库；R 返回道路，无 NPC 自动泊车。

右上角「设置」打开分类弹窗，包含驾驶、自动驾驶、快捷键、车载设备、NPC 交通、地下停车场、世界与道路、天气与时间、性能画质、声音、我的预设和探索工具。打开时暂停行驶与设备动画，声音页可即时试听；点击「返回旅程」或 Esc 关闭并重新按键继续。原有暂停状态独立保留，种子或道路应用后返回场景。

自动驾驶默认 `;` 开关、单引号 切换控制模式（同时退出，需重新开启）、`− / =` 调最高巡航速度。可选速度与方向、仅控速、仅控方向；舒适度 1–5 档，最低巡航偏好 0–160 km/h、最高巡航速度 10–160 km/h，最低不能高于最高。弯道、低抓地力、前车和道路边界优先减速直至停车；仅控方向时由玩家负责制动。控速模式自动换挡，制动、手刹、手动换挡或操作受控方向 / 油门立即退出。沿当前路线保持车道，不自动换道、选匝道或泊车；极窄弯道和极端坡度需接管。辅助参数主动保存到本机，开启状态不保存。

「快捷键」点击操作后的按键重新绑定，支持单键或 Shift 组合，冲突会提示，Esc 取消；可恢复全部默认。按键自动保存到当前浏览器，与世界预设分开。`M` 菜单显示实时映射；下文按键均为默认值。新增 `Shift+T` 自动 / 手动变速箱、`Shift+M` 载具面板、`Shift+P` 设置、`Shift+G` 停车补液、`Shift+L` 灯光亮度、`Shift+B` 灯光距离、`Shift+C` 视角回正、`Shift+V` 开关声音。Esc、Tab 和系统组合键保留。

「驾驶与视角」可选择科技数字、经典指针或极简速度表，所有车型通用。仪表下方「载具面板」显示当前车型的尺寸、质量、输出、限速、轴距、座位数、悬挂与设备状态，可进入对应设置或座位图。打开面板冻结行驶，关闭后重新按键继续；预览车型时不提供换座。

「我的预设」可命名保存、更新和删除最多 32 个本机预设，并导出当前设置为 JSON。保存世界种子及道路地形、车型调校、仪表样式、常用设备、天气、画质和混音参数；不保存位置、车速、里程、当前座位或设备消耗。导入文件先校验与预览，点击「应用预设并返回起点」才重建世界；导入后需要主动保存才会留在本机。普通命名预设需手动应用；另可「保存当前为启动设置」，下次打开自动恢复参数并返回起点，后续修改需再次保存。链接中的种子优先，取消启动恢复不删除命名预设。单文件最大 64 KB，清除网站数据会删除本机预设，导出文件可作备份；存储不可用时仍能游玩和导入导出。

当前使用格式 9 预设，包含 NPC 上限、车流场景、车库车队、楼层加载、照明及性能设置。早期预设需重新配置并保存；浏览器中的旧数据不会被覆盖，也不会自动迁移。

「驾驶与视角」可选五档悬挂和 70–130% 阻尼、50–90° 视野、5–20 m 基础跟车距离及 -10 至 +35 cm 视角高度。视角调节即时预览。拖动观察或双击锁定鼠标，按 Esc 释放；「视角回正」恢复正前方。第一人称过滤悬挂旋转，跟车镜头检测山体遮挡并缩近；隧道内限制跟车距离和高度。雨天抓地降低，夜间及隧道自动开灯。

「动力与外观」可调最高速度 20–400 km/h，前进限速与变速箱齿比一起调整，实际能否达到仍取决于动力、坡度和抓地力，倒车保持车型原限制。自选限速换车后保留，恢复默认重新使用各车型原限速。随车速增大转弯半径的辅助默认开启，强度可调 25–200%；关闭后允许更大转角，实际转向仍受轮胎抓地力限制。参数在上下车和换世界时保留，只有主动保存的预设会留在本机。

默认自动变速箱，普通乘用车与摩托车 6 挡，超跑与重型车 8 挡。按 `[` 降挡、`]` 升挡会进入手动模式，设置中可返回自动；S 保持制动及低速倒车操作。仪表显示实际前进挡与转速，换挡短暂降低动力并播放衔接音，危险降挡被拒绝。超级跑车默认 620 kW、350 km/h，采用 8500 RPM 红线、低重心与较硬悬挂；实际极速受动力调校、坡度和抓地影响。采用简化传动模型，没有离合器踏板或机械故障熄火模拟。·（Backquote） 点火 / 熄火，普通车起动约 0.75 秒，重车约 1.25 秒。只有驾驶员可操作；发动机关闭时没有驱动力，仍可滑行和刹车，附件继续供电。

L 切换自动／关闭／近光／远光，亮度可调 25–200%，远光距离 80–800 m，仍受天气与遮挡影响。Q 左转灯、E 右转灯、H 双闪，再按取消；转弯回正后单侧信号自动取消。B 切换雨刮模式，自动随雨量调速，摩托车不提供雨刮。雨天驾驶舱内可见水珠与水痕，刮片扫过后清除对应区域，随后重新积水；雨停或进入隧道后逐渐变干，暂停冻结水膜。水膜是轻量视觉效果，没有真实折射流体。换车保留调校及灯光设置。

G 喷玻璃水并自动补刮，水箱为 3 L，可在「车载设备」中停车补液；《 / 》所在的逗号 / 句号键按住升窗 / 降窗，松开即停，也可用滑杆按 1% 调整开度；T 收合敞篷跑车车顶，超过 5 km/h 时禁用并暂停已有动作；V 按住鸣笛。N 循环关闭与 1–6 档空调风机，K 开关氛围描边灯，U 开关阅读灯。车窗与敞篷为简化开合动画，车窗只控制驾驶室部分，摩托车不提供玻璃与座舱设备；通风只增加设备音，没有温控模拟。

P 打开座位地图，停车后可选择驾驶位、乘客位或吊车操作席；客车各排座位均可选择，乘客不能控制车辆行驶。PageUp / PageDown 调座椅高度，方向键前后左右微调，Home / End 调靠背，Backspace 重置当前座位。镜头与座位位置一致，调整分别保留在本次运行内。所有车型的车内屏幕显示车速、挡位、转速、行程公里数、风速、电台与设备状态，转向灯同步闪烁。M 打开操作菜单和完整快捷键表；菜单、座位图与设置独立保留原有暂停状态。

8 米、12 米与 15 米客车分别有 9、13、18 排乘客座位，每排 2+2，另设驾驶位，共 37、53、73 席。13.5 米双层客车下层 12 排、上层 14 排，共 105 席；座位图上方选择 1F / 2F，停车后任意就坐，各层视角对应真实车内高度。楼梯为模型细节，车内换座使用座位图。

J 开合驾驶室车门或客车乘客门，Y 开合行李舱、厢式货车或半挂尾门、平板装载坡板；I 控制超跑尾翼、吊车工程警示灯或摩托驻车支架。驾驶位可用快捷键，也可在车载设备与载具面板中点击对应按钮；车门、舱门与支架收妥才能起步，乘客不能操作。尾翼和警示灯可行驶中切换，尾翼为视觉调节，不改变下压力。载货与坡板为无载荷动画，不含装卸或货物碰撞；开合状态不写入设置预设。

移动吊车停车后按 P 进入后部操作席，O 展开支腿并启动。支腿完全展开后，W / S 抬落吊臂、A / D 回转、Q / E 伸缩、Z / X 收放吊钩；O 再按一次自动收车，完全收妥后才能由司机行驶。操作席镜头和状态屏随转台旋转。这是无载荷操作，不含吊装受力、吊物与周围碰撞。

车辆采用逐轮弹簧与平面转向模型，支持道路、桥面、服务区地坪与匝道接触，以及护栏、服务区主要建筑、停车车辆和 NPC 车辆的简化阻挡；没有完整刚体翻滚、树木或全场景碰撞。18 米高栏仓栅半挂采用开放货台与三轴挂车，沿用铰接、内轮差和倒车折叠约束。当前支持桌面键盘操作，没有移动触屏或手柄驾驶。所有车模与 UI 在项目内原创实现。

「退出驾驶」或「退出步行」保留当前位置并切回自由相机。驾驶时点击「开始步行」与 F 下车相同；点击景观定位、返回起点或更换世界会退出当前模式并清除停车状态，之后可在新位置附近重新开始。自由探索的操作如下：

| 操作 | 按键 |
| --- | --- |
| 飞行 | W / A / S / D |
| 上升 / 下降 | Space / Shift |
| 四倍加速 | Ctrl |
| 观察 | 按住鼠标左键拖动 |
| 锁定 / 释放鼠标 | 双击画面 / Esc |
| 暂停飞行、云与雨 | 斜杠 / 或 Pause |
| 调试面板 | 反斜杠 |

左侧可修改种子、调整飞行速度（20–1200 m/s）、返回起点和切换地形线框。默认开局随机，可点击「随机新旅程」；使用 `?seed=CLOUD-ROAD-001` 或手动输入种子可重现世界。自由相机不受碰撞约束，可穿过地形。

起点前后均有道路，掉头或倒车可进入反方向路线。每条路线在 20、40、60 公里等里程生成一处右侧出口，每处仅一条支路；驶入后沿该支路继续加载并独立计程，里程包括入口匝道。山路和高速可生成环形高架出口。点击「下一匝道」可增量定位远处入口并显示进度。未选分支只生成附近预览，远处道路回收后可重建。主线全直道选项仍保持直行，驶入岔路会改变路线方向。分支不是交通导航图，没有自动驾驶或导航寻路。

「山路岔路」控制山路出口，「双层高速互通 / 山路匝道」控制高速互通并升级山路岔路；应用后重新生成。双向高速每 20 km 一处完整互通，上下两条高速垂直交叉，四条右转匝道与四条左转环道连接四个来向，玩家驶出后继续无限生成。上层抬高 14 m，局部可超出海拔区间；匝道宽 7.4 m、独立坡度不超过 6%，主线沿用坡度与车道设置。山路、单向高速保留原分支匝道，低坡度或净空不足时使用平面分流。出口附近预留直路，服务区错开入口；「下一匝道」再次点击可俯瞰高速互通。NPC 仍在主线上行驶，不自动选择匝道。

路线会为深谷大桥保留直线路段：高桥拱结构用于平直或轻微弯曲、绝对纵坡不超过 1% 的桥面，急弯或陡坡沿用实心墩梁桥。穿山隧道跟随道路自然深埋范围，无固定长度上限，也不因急弯、盘山阶段或加载边界断开；极端直道／坡度设置仍可能需要长高架或局部切坡。洞口标牌显示 TUNNEL 与公里长度，未探明出口显示 ≥ 已确认长度；洞口加密顶灯，内部放疏，配有侧壁引导灯和同向绿箭头 / 逆向红叉。服务区与互通避开深埋范围，长隧道处实际设施间距可能超过原计划。

高速转向随车速、轴距与车型稳定性平滑收小，减少高速轻触方向就进入轮胎转弯极限的问题；低速保留转弯和倒车能力，发卡弯仍需提前减速。

「地貌与道路」可选择高山雪岭、森林山谷、草甸丘陵、喀斯特峰林、沙丘旷野、沙漠峡谷、红岩荒原、火山高地、冰蚀苔原或阔叶丘陵。道路可选山路、双侧 LED 路灯景观大道或高速。单幅沥青宽度 5–12 米、步进 0.5 米，不含路肩；山路和大道双向可选总共 2 / 4 车道，单向可选 1–4 车道；高速每向 1–3 车道，双向时中央分隔带宽 4 米。最小车道宽度为山路／大道 2.5 米、高速 3 米，增加车道会自动补足路宽。单向道路只有同向 NPC，玩家仍可自由驾驶。点击「应用并返回起点」重新生成世界，保留季节、光照、云层及植被开关。森林混合松树、阔叶树、林下灌木与草丛，近景增加穗头与杯状野花；干旱地貌有仙人掌与矮灌丛，「植被」可控制显示。

「山脉海拔」可保留原生高度，或自定义 0–6000 米的天然地形高低区间；峰谷位置由种子决定，不会在边界截成平台。山脉密集度为 25–200%，越高峰谷间距越短。植被密度为 0–200%，影响树木、灌木、草花与地表点缀，0% 不生成；坡度、地貌、积雪与道路避让仍生效。应用后重新生成世界，天然地形范围不包括道路开挖。

「季节、天气与时间」可手动选择四季，换季不重置车辆、道路或树木位置。春季有花簇和嫩叶，夏季绿叶繁茂，秋季彩叶、落叶与枯穗，冬季裸枝和寒地积雪。路面、桥梁及服务区外部表面同步变化，雪路保留轮迹。温度随地貌和海拔变化，温暖沙漠不覆盖积雪；低温降水自动变为雪或雨夹雪。雪路抓地力降低，隧道内免除季节积雪惩罚；仪表显示当前季节与路况。雨刮自动档和雨声音量跟随液态降雨，手动雨刮继续可用。季节不随时间自动推进，积雪为材质效果，暂无动态雪层厚度。

「蜿蜒程度」可选五档：1 档舒缓山路、2 档蜿蜒山路、3 档盘山折返、4 档密集发卡弯、5 档连续发卡弯；档位越高，折返越密、弯道越紧。另可选「全直道 · 零弯道」，始终沿同一方向延伸。山路与高速均适用，原挂壁／高架盘山独立选项已移除，蜿蜒选择不改变天然山形。

「高速主线最小转弯半径」可调 50–2000 米，默认 200 米，选择高速后启用。限制的是主线中心线的最小平面半径，实际弯道可以更缓；所有蜿蜒档位及服务区前后均受约束，全直道仍不转弯。设置通过限制每段曲率逐步完成折返，保持流式路段长度和网格预算；匝道独立设计。点击应用后重新生成，换种子或故障重试保留选择。

「最大坡度」可调 0–40%，默认 6%，同时限制上坡和下坡。0% 为水平道路；40% 表示每水平前进 100 米最多升降 40 米，实际坡度仍随地形变化。全直道可以上下起伏，配合 0% 可生成水平直路。选择后点击「应用并返回起点」重新生成，换种子与故障重试保留选择。近处路旁增加草叶与白、黄、淡紫野花，随玩家移动加载和回收；花草避让路面、设施、陡坡、干旱与积雪区域。

「上下坡节奏」可选自然起伏或上下山偏好。目标爬升范围为 50–2000 米，50 米步进，用于选择更合适的上山或下山方向；实际道路仍跟随山体，地形下降时可以提前下山，平地不会为满足目标抬高。目标不是绝对海拔，也不保证每次达到；最大坡度继续生效，0% 保持水平。「山路十八弯预设」选择 5 档、25% 坡度与上下山偏好，保留有效范围，点击应用后生效。

另可选择「固定海拔往返」或「区间内随机升降」，道路海拔上下限为 0–6000 米，起步方向可选从下限上山、从上限下山或种子随机。固定模式在上下限附近交替换向，随机模式交替选择区间内的高低目标；接近目标时缓坡过渡，遵守所选最大坡度。0% 坡度保持起始海拔，上下限相等时为水平路线；匝道跨越高度不足时改用平面出口。绝对海拔优先满足道路高度，可能需要高桥、深切坡或隧道；若希望道路贴山，请选自然起伏。

「下一服务区」定位并俯瞰下一处停车与补给场地。服务区按道路里程约每 10–20 公里生成，高速两侧各有连接匝道。高档蜿蜒及大坡度路线在入口附近预留短段缓弯缓坡，保障场地空间。场地或匝道落差超过 5 m 时使用架空平台和支撑柱，外缘配有钢护栏，保留出入口与下方自然山谷。定位期间可继续探索，暂停或公告会暂停定位，返回起点可取消。建筑按地貌与站点轮换木屋、现代平顶和庭院外观，新增两层商场店面、厕所入口、廊架、屋顶设备、长椅与垃圾桶。单侧停车场约 160 × 220 m、108 个车位，划分小车、客车、货车、半挂和摩托五区，有箭头、分区标牌、车位线、斑马线与照明。每区按种子随机停放对应车型；走到车门旁按 F 可原地上车驾驶，提示选择可到达的最近入口。换车后原车留下，可取回位置、里程与调校，挂车姿态独立保留。借车使用该车自己的调校；车漆、座位调整和活动设备状态不随停放车保存。商场、厕所只提供外观，无室内、购物、充电、加油或休息交互。

「性能与画质」新增植被精度距离 50–150%、远景树木保留量 0–100%、近景／中景植被投影、每帧更新 1／2／4／8 个植被地块，以及其他车辆精细距离 120／240／480／960 m。远处车模降级，靠近恢复；切换保留旧模型直到新模型可用，碰撞不随 LOD 改变。较低更新预算减少集中更新，但补齐较慢；LOD 尚无渐隐。

「性能与画质」提供节能／均衡／精细预设，联动渲染比例、投影精度、抗锯齿、云层和视距。可分别设置 50–200% 的 3D 渲染比例、关闭／1024／2048 投影、关闭／轻量 FXAA／2× + FXAA／4× + FXAA 抗锯齿、三档云雾细节，以及约 1.5 / 2 / 3 / 4 公里视距；文字始终保持原有清晰度。FXAA 在现有合成中平滑场景边缘，低性能设备可用轻量 FXAA 搭配轻量云雾；它不是时域抗锯齿，细小植被仍可能闪烁。30 / 60 / 90 / 120 / 144 / 165 / 240 FPS 或不限帧率的设置独立保留，不限帧率仍受浏览器和屏幕刷新率约束。即时生效、保留位置，换世界也保留选择；页面进入后台时停止渲染。较远视距需要更多加载时间与显存，天气和云层仍会限制实际能见度。

深谷大桥下可遇到公路或铁路高架景观，两端接入山体隧道，主桥支撑避让下层线路。「桥下交通景观」可观察附近符合地形条件的跨越点；没有可用地点时按钮禁用。最多同时绘制三处并随路线回收，没有列车交通或铁路驾驶，驾驶请沿主路和岔路探索。

「声音与音乐」中点击「开启声音」。总音量、全部音效、音乐、发动机与换挡、胎噪、山野、风雨、车内设备及喇叭提示音分开调节；车内按 1–9 / 0 播放十个电台频道，也可在设置中选台；三种音乐氛围可调节奏，提供发动机、换挡和喇叭试听。超跑、摩托与柴油车采用不同发动机音色，重车增加倒车提示与气刹声；音乐增加低音、轻节奏、和声起伏与换台淡入。雨天胎噪、鸟声与夜间虫鸣跟随环境变化，驾驶室开窗与敞篷改变环境音隔绝程度。音源为程序合成，混音输出经过动态压缩。暂停、公告、窗口失焦和后台暂停音频，恢复前应用新音量并淡入，复用同一上下文。总音量或音效与音乐都为零时停止音频处理；混音参数可存入预设。下车后附近车辆的车灯、雨刮和转向灯继续工作，暂停或设置弹窗冻结动画。

附近地形加载后，后台继续准备前方一圈地块和细节升级，跨入新区域时复用数据。驾驶时跟随车辆行进方向，回头观察不会带偏预加载；自由探索时跟随镜头朝向。缓存最多 128 项，过期数据与远处网格会回收。反斜杠 可查看已预加载和正在预加载的数量；超高速飞行与远距离瞬移仍可能超过生成速度。

高山雪岭路线从低缓山谷爬升，经过两侧山脊之间的垭口后下降，再进入下一片山地。「下一垭口」可定位前方的山口，旁边显示当前路线阶段；定位支持暂停、公告暂停和返回起点取消。其他地貌不提供此入口。

「天气与时间」提供晴天、多云、小雨、雨天、风雨和浓雾六张单选卡片，可点击整张卡片或用方向键选择；搜索“天气 浓雾”等可直达选项。窄窗口使用两列，月球和火星禁用地球天气，返回地球恢复选择。设置打开、分类定位与折叠内容有轻量动效，尊重系统“减少动态效果”偏好。时段可选清晨、午后、金色时刻、橙色晚霞和夜晚，默认金色时刻。「光照时刻」支持 07:00–22:00 连续微调；「望向太阳／月亮」调整朝向并继续探索，「山体投影」控制附近地形与桥梁的阴影。天气与时间即时生效，换种子保留选择，没有自动昼夜循环。云层开关不取消天气雾。

「隧道入口」移到附近洞口前方，调低速度后按 W 前进并用鼠标跟随道路弯曲。山路为单洞，高速为双洞；进入洞内后雨线和云雾减弱，保留内部照明。没有符合条件的隧道时按钮暂不可用。「灯光路段」移到分段布置的路灯旁，选择夜晚可观察照明；「路灯」开关只控制室外灯具。反斜杠 显示隧道数、遮蔽程度与附近亮灯数。

控制面板在矮窗口内可滚动，也可用右上角按钮收起。按钮获得焦点时仍可使用 斜杠 / 或 Pause 暂停和 反斜杠 调试，编辑输入框和阅读公告时不拦截这些按键。暂停、编辑种子、打开公告或窗口失焦会清除旧按键状态，恢复后需重新按下移动键。公告和调试面板的关闭按钮在滚动内容时保持可见。

地形或图形故障期间，探索控件暂不可用，相机与云漂移停止；公告仍可查看。地形故障可「重试当前世界」，保留光照和显示设置；图形上下文恢复后自动重新启用操作。3D 启动失败时提供页面重新加载入口。

点击「道路视角」移动到水平距离最近的路段上方；「发卡弯视角」俯瞰折返弯，「桥梁视角」从侧面观察已生成的高架桥，观察位置会避开地面。「路线骨架」默认关闭，开启后显示可穿透地形的中心线和控制点。反斜杠 可查看道路里程、坡度、曲率、驻留路段、发卡弯、桥梁与支撑数量，以及相机下方地面的生物群系、海拔、坡度、积雪比例、雪线和程序化温湿度。反斜杠 地面数据与坐标一起采样，底部海拔仍表示相机高度。

点击「穿云起点」进入附近安全的低谷，按住 Space 上升，穿过浓雾后拖动视角俯瞰云海；Shift 可下降返回。「云层」控制显示，反斜杠 可查看云下／云中／云上、当地云顶与雾的范围。附近没有足够低的谷地时会提示重试，不会把相机放进山体。穿云入口自动开启云层，普通换种子保留开关设置。

## 验证

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:pages
```

端到端测试自动构建并启动生产预览，使用独立的 `127.0.0.1:4318` 端口。覆盖东西／南北方向各 30 公里实际飞行、道路增量生成与回放、种子切换、原点重定位、资源回收、暂停和输入失焦。单元测试另覆盖 10 / 30 / 100 公里的地形与道路非渲染模拟、跨 LOD 接缝，以及真实路面／地形三角形的射线间距检查。

启动开发服务器后可测量 1080p 连续飞行性能：

```sh
npm run benchmark
# 标准视距 / 4 km 视距连续驾驶
npm run benchmark -- --drive
npm run benchmark -- --drive --far
# 指定蜿蜒程度：0 为全直道，1–5 为五档山路
npm run benchmark -- --far --route=5
# 高速连续驾驶
npm run benchmark -- --drive --highway --far
# 可指定已运行的开发服务器或生产预览地址
npm run benchmark -- http://127.0.0.1:4173
# 比较画质选项；--far 可覆盖预设的视距
npm run benchmark -- --drive --far --quality=economy --fps=30
npm run benchmark -- --drive --quality=balanced --scale=0.75
```

报告包含 GPU 名称、实际画布分辨率、渲染帧率、屏幕刷新帧率／帧间隔和超过 50 ms 的主线程任务。限帧时以 `fps` 为实际渲染帧率，`displayRefreshFps` 表示浏览器刷新回调频率。macOS 测试使用 Metal，其他平台由 Chromium 选择渲染后端；软件渲染的测量不能代表硬件加速性能。

驾驶测量只持续按住油门，不会自动转向，弯道可能触碰护栏并减速；测量持续流式加载可省略 `--drive` 使用飞行模式。

## 实现

- TypeScript、Vite、Three.js / WebGL2，原生 HTML 控件。
- 确定性 PRNG、坐标哈希梯度噪声、分形山体、山脊和 domain warp。区域噪声改变谷宽、侧脊、森林起伏、盆地、台地高度和峡谷横剖面；两组交错方向的沙丘随区域混合，远坐标保持连续。
- 256 m 分块：5×5 高精度（64 格）、9×9 中精度环（16 格），外层为低精度（8 格）；按视距保留 169 / 289 / 625 / 1089 个活动分块，道路附近额外提升至 64 格。
- 各级 LOD 共用 4 m 边界节点与连接，保持几何和着色属性连续；远处分块保留粗网格内部。
- 1–4 个 Worker 根据局部道路走廊快照计算耦合后的高度、法线和颜色，使用 transferable buffers 回传；主线程每帧最多应用两个结果，并设置约 2 ms 的开始处理预算。
- 生物群系按地貌、海拔、坡度及种子温湿度噪声混合山谷、森林、岩石、高山、雪区与沙漠颜色。各地貌有不同高度函数，岩层颜色随高度起伏，跨分块和 LOD 的属性保持一致。
- Worker 按实际地形三角形生成树木、灌木、草丛和碎石，覆盖分块边界并避开陡坡、雪区、道路和设施。近树、地被与远景树冠共用九个实例批次，近处 3×3 分块的细草、野花和紫色穗状花另用三个批次；远景按全局候选单元固定抽稀，随所选视距加载与回收，使用局部缓冲更新和浮动原点移动。
- 山体材质以世界坐标叠加程序化草地与岩面细节，细颗粒随屏幕覆盖范围衰减，不使用外部纹理；山体几何保留低多边形风格。
- 共享材质，按 LOD 复用 Mesh、Geometry 和 GPU 属性缓冲；卸载分块返回有界池。仅池溢出、换种子或销毁世界时释放资源。
- 相机水平距离超过 5 km 后重定位渲染坐标，逻辑坐标保持不变。
- 云场由种子生成一张 128×128 周期纹理，云底 1800 m、云顶在约 2300 m 附近起伏。沿视线最多 24 次体积采样在一次全屏合成中按场景深度遮挡，加入两次太阳方向遮光采样，与相机高度雾配合完成穿云；使用逻辑坐标和有界风偏移，兼容浮动原点。场景颜色只在最终输出时做色调映射，渲染目标和云纹理复用。
- 太阳方向、暖光、天空渐变、远景薄雾和云层着色共用光照状态；天空与雾在现有全屏合成中计算。近中景地形、道路与桥梁投射 2048² 局部阴影，按逻辑世界的灯光空间对齐阴影网格，保持原点重定位前后稳定。
- 近处分块优先，并在相机转向时重新按朝向排序；道路重放期间也会回收远处分块并丢弃过期结果。
- 高山地形沿南北投影每约 32 km 生成一组独立种子山地，高速拉长至约 64 km，峡谷走向同步舒展；谷底、垭口位置和高度变化，边界高度与坡度连续。谷地两侧低缓，垭口两侧山脊更高；参数缓存有界，任意远处可确定性重建。
- 普通道路候选评分结合地形落差、悬崖代价、坡度、曲率和种子引导，高山路线额外追踪谷线与垭口走势；积分平滑变化的方向与坡度，保持路段接缝的位置、切线与曲率连续，横坡随曲率变化。
- 1 档保持普通缓弯；2–5 档折返组依次包含 2 / 4 / 8 / 连续发卡弯，发卡弯长度从 272 m 逐级缩短到 160 m，转角约 130–150°，最小半径约 30.6 m。组间和弯间间隔逐级缩短。服务区附近短暂舒展；所有档位遵守自选坡度上限。
- 天然高度场与蜿蜒档位独立，路基只在道路与设施附近局部耦合，不再使用挂壁专用塑形。
- 道路总体沿北向走廊推进，保持中心线不自交。二维空间索引用于最近路段定位及 Worker 走廊裁剪，支持反向或不连续的局部道路片段。
- 1 档高速独立采样远处谷线或 400–1800 m 前方地形，保留约 1.2 km 最小转弯半径；2–5 档与山路共用折返生成。0 档锁定方向、曲率及横坡为零。两种道路均遵守 0–40% 坡度上限，坡度逐段平滑变化。
- 路基宽度随车行道配置变化，跟随道路高度和横坡，向外平滑切坡或填方。高速采用独立双幅路面、中央分隔和护栏。桥跨内部取消填方，真实桥头在相邻采样之间衔接路基。
- 道路中心与两侧路基边缘采样垂直落差，>5 m 优先架桥，填方不超过自然地面以上 5 m，主路土方影响半径不超过 64 m。短桥和开放长桥均可生成，窗口边缘不视为真实桥头。桥下取消填方，靠山侧保留净空切坡；主桥连续通过服务区，只在匝道出入口开放护栏。普通桥墩按绝对里程每 48 m 布置，随高度连续加粗；低桥交替使用实体墩与圆形双柱，高墩为渐收实心墩。超过 150 m 的平缓高桥在相邻墩间加入拱肋、拱上支撑与横向连接，急弯或陡坡使用梁桥。下层交通交叉处局部留空，其余墩位不移动。满足完整直线规划、绝对纵坡 ≤1%、两处主墩均 >200 m 及地形净空要求时，以独立斜拉长跨替换中央普通跨，主墩加粗并加宽盖梁，高速共用一组外侧门式塔柱。超过 100 m 保留红色钢护栏，连续箱梁深度随单幅路宽调整为约 2.12–2.60 m，基础采样四角并入土。桥头翼墙只出现在真实桥端，向陆地展开并埋入天然地面。混凝土包含低反差模板缝、孔隙及水痕，无外部纹理。方向箭头每 2 km 一组，标线公共周期 78 km，避免回收时漂移。
- 天然地面高于全幅道路 11 m 且曲率适宜时检测隧道，保留路基地形并添加拱形衬砌和覆盖网格，洞口真实留空；高速按两幅道路分别扫掠。蜿蜒路线保留露天折返组。洞内加入加强带、排水槽与反光标记，洞口覆盖层逐渐退入山体，复用地表纹理；覆盖区排除原地形植被。
- 道路护栏、灯杆与灯头使用共享实例批次，按逻辑里程分段布灯。固定四个无阴影点光源只照亮相机附近路灯或隧道灯；几何版本变化时更新，原点移动只平移批次。雨线在天空合成后绘制，并读取场景深度实现遮挡。
- 服务区以 15 km 周期加入种子偏移，完整窗口内评分选址，目标间距 10–20 km；深埋路段顺延。停车场与匝道地形传入 Worker，匝道保留主路横坡后平滑过渡到场地；服务区排除隧道，高落差场地改为架空平台和匝道，不取消主桥。支撑柱落到自然地面，平台与匝道护栏共用渲染和碰撞边线，底面阻挡步行跳跃。模型和标牌使用共享实例批次及原创像素字形图集，照明复用附近四灯池。停放车辆从实际车模生成静态模板，每帧最多建立一种车型；按车型和挂车最多 21 批绘制，以 1600 m 范围筛选，移动 300 m 或车队变化时刷新；仅当前驾驶车辆持续运行物理。停车状态只留在当前世界内存，最多记录 512 个已借走标记和 64 辆换车留下的车辆，超出后回收最旧记录；更换世界或刷新清空，不进入预设与发布产物。
- 道路窗口前后各预留至少 4000 m（南北投影），最远视距扩到 6208 m，涵盖地形、预加载窗口和结构检测范围；覆盖就绪后才调度地形，后退时也会补齐覆盖。最多保留 256 个路段，普通段 96 m（发卡弯 160–272 m）、48 个采样间隔；中心线和路面共用缓存。路面使用一个复用网格和原创 GLSL 沥青／标线材质；所有标线按道路里程连续排列。

道路约每 2048 m 缓存完整生成控制点，最多 64 个；向前或向后重访已缓存区域、查找服务区或垭口时复用检查点，保持同种子生成一致。未缓存区域仍需从更早位置或起点重放。当前不保存玩家状态。后续保存功能只应写入浏览器存储，不应写入仓库或构建产物。
