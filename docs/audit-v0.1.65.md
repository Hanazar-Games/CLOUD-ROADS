# v0.1.65 检查记录

本次发布纳入旅途路书，并检查 UI / UX、SFX / BGM、车辆操作、物理、世界生成与故障恢复。检查基于本机 Chromium / ANGLE Metal、现有全部单测与浏览器场景；不将自动化通过等同于所有随机种子绝对无缺陷。

## 检查范围

- 路书：1 / 3 / 5 km、正反方向、海拔与坡度、短起伏累计升降、桥隧边界与未知出口、设施排序、未加载边界、道路窗口回收、大坐标、不同地图、关闭后不更新、桌面 / 窄屏 / 短屏、相邻标记错开、改绑与本机恢复。
- 驾驶与世界：全队列既有测试覆盖车辆尺寸、模型与设备、上下车和车内步行、司机 / 乘客权限、RPM / 换挡、EV、漂移与护栏碰撞、摩托车转向、NPC 行驶 / 变道 / 喇叭、自动驾驶、双向流式道路、桥梁、天然隧道覆土、匝道、服务区、车库、天气与季节、浮动原点、图形与地形错误恢复。
- UI / UX：设置分类、搜索、折叠、精确数值、预设 JSON 与启动恢复、按键冲突 / 重绑、焦点和按键清理、暂停保持、历史公告及各尺寸弹窗布局。
- SFX / BGM：全量覆盖十个音乐频道、快速调台、独立静音、试听、发动机 / 换挡、车型喇叭、附近发动机、碰撞与设备声、音乐避让、失焦和音频失败。新增原生 AudioContext 检查路书多次暂停 / 恢复、暂停时音频时钟停止、图形故障恢复及不增加音源数量。
