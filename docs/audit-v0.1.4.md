# v0.1.4 检查与修复记录

检查范围：现有 UI / UX、键盘与鼠标输入、暂停、图形和 Worker 故障恢复、公告、天空／云层／阴影、长距离生成及资源回收。本次保持 Phase 9，不进入 Scenic Director 或车辆阶段。

## 已复现并修复

| 问题 | 复现与影响 | 修复与验证 |
| --- | --- | --- |
| 按键连发恢复旧移动 | 按住 W，焦点移到种子输入框再返回画布；后续重复 keydown 重新触发飞行 | 忽略清除状态后到达的旧连发；暂停／继续统一清空输入，实际键盘测试验证重新按下后才能移动 |
| 按钮焦点阻断快捷键 | 点击「收起面板」后，P 无法暂停，F3 无法打开调试 | 非编辑控件可使用 P / F3；保持文本输入、滑杆与公告中的原生键盘行为 |
| 故障期间仍可探索 | 注入 Worker 发送失败后，仍能按 W 改变坐标，探索按钮仍可操作 | 故障时清空并禁用输入，停止相机与云漂移，探索区域设为 inert；提示获得焦点，公告与重试入口保持可用 |
| 关闭长公告不便 | 在 1024×450 窗口滚动到最旧公告，关闭按钮离开视野 | 公告标题栏固定于滚动容器顶部；验证按钮始终可见、可关闭且焦点返回公告入口 |
| 窄屏调试面板覆盖设置后不易关闭 | 390 px 宽窗口中，F3 面板拦截种子提交按钮的点击；输入框焦点下 F3 保持原生行为 | 自查后补上可见关闭按钮，标题栏滚动时保持可见；验证关闭后可正常点击种子输入框 |

前四项先以浏览器回归测试复现失败，再实现修复；第五项在实际截图与操作自查中发现，同样先复现再修复。没有删减原有功能或跳过失败用例。

## UI / UX 与恢复自查

- 速度和光照滑杆的操作区域从 3 px 扩大到 24 px，总布局高度保持一致；速度控件补充可访问的单位读数。
- 图形上下文丢失时暂时禁用探索控件；恢复后重新启用并清除旧输入。Worker 故障仍存在时保持错误状态，需显式重试。
- 验证地形故障期间打开公告，再丢失／恢复图形上下文：公告保持焦点，地形错误未被错误清除；关闭公告并重试后恢复飞行，保留光照与阴影设置。
- 错误面板位于调试面板上方，提示获得焦点；启动失败时禁用无效的探索控件，保留页面重新加载和版本公告。
- 实际检查 1440×900、1024×450、390×844：滑杆、控制面板滚动、调试关闭、长公告关闭、错误层级与恢复操作正常，无横向页面溢出。窄屏检查只代表布局验证。
- 当前公告升级为 0.1.4，0.1.3 原公告完整移入历史；版本号、README 与开发记录同步。

## SFX / BGM

代码和资源检查确认：仓库尚无音频文件、声音模块、Web Audio 初始化或音乐播放流程。当前为静音的世界引擎开发版本；没有可供试听的音色、混音、循环衔接或自动播放流程，本次未把这些项目标为通过。界面、README 和公告保留明确的能力说明。

## 验证结果

- `npm test`：18 个测试文件、78 项单元测试通过，包含 10 / 30 / 100 km 非渲染模拟与生成确定性检查。
- `npm run test:e2e`：27 项测试通过，包括本轮 5 项交互回归、图形与 Worker 组合故障、30 km 实际飞行、换种子资源回收，以及落日／阴影／穿云画面检查。
- `npm run lint` 与 TypeScript / Vite 生产构建通过；实际 UI 自查无页面或控制台错误。
- 首轮修复后 14 项交互与故障测试通过；自查补修调试面板关闭入口后，再运行上述完整回归。

## 性能与边界

Apple M5 Pro / Chromium / ANGLE Metal / 1920×1080，金色时刻与阴影开启，连续飞行 10 秒平均 60 FPS，p95 与最大帧间隔约 16.8 ms，未记录到超过 50 ms 的主线程任务；末帧 193 次 draw call、6 张 GPU 纹理，正在补齐新进入区域的分块。这是单机短时抽测。

浏览器验证覆盖 Chromium / Metal，未声称完成跨浏览器、低端硬件、长期压力或真实屏幕阅读器验收。车辆、碰撞、植被、SFX / BGM 仍未实现。构建仍有 Three.js 导致的 500 kB 包体积提示。
