# v0.1.63 检查记录

本次发布包含 v0.1.62 之后的道路、岩层地形、植被、充电桩、雨刮与远征车细化，以及以下经复现确认的修复。

## 问题与修复

| 问题 | 复现与原因 | 修复与回归 |
| --- | --- | --- |
| 静音预设仍创建音频资源 | 保存声音关闭的预设，应用后统计原生 AudioContext：预期 0，实际 1。恢复频道复用了主动选台的开启声音逻辑。 | 预设恢复期间只恢复频道，最终按保存的声音开关执行；恢复标记在异常时也会清除。浏览器检查应用、启动恢复、主动选台和有声预设恢复。 |
| 双层客车楼层选择丢失键盘焦点 | 座位图用 Enter 切换 2F，新的楼层按钮未获得焦点；刷新座位图调用了关闭、重开弹窗。 | 已打开的弹窗就地刷新，焦点回到所选楼层按钮。检查 Enter、Space、Esc、小窗口及关闭次数。 |
| 长车身乘用车反光条悬空 | 远征车与加长礼宾车套用重车安装高度，部分反光条高于引擎盖侧板。 | 按车身类别降低安装高度、收窄侧面标记；保留长车侧灯间距，以真实网格射线检查两端及上下边缘。 |
| 远征车近远景轮廓不一致 | 远景沿用普通 SUV 车身高度与四轮简模，反光条缺少车身背板。 | 对齐远景车身与舱顶高度，保留六轮、行李架、货箱和备胎；检查反光条实体支撑与顶点预算。 |

## 覆盖范围

- 道路与地形：同种子重建、道路宽度与坡度、蜿蜒等级、贴山选线、路肩支撑、桥隧、立交、服务区、地下车库、双向及长距离流式加载、浮动原点和图形恢复。补充红岩荒原的高度复现、连续性及不同 LOD 分块边界检查。
- 新模型：远征车支架与装备边界、近远景反光条、全车型模型尺寸与部件预算、雨刮运动与实际雨水擦除、暂停冻结、松树树冠、充电枪与线缆净空、近景细节分级及资源释放。
- UI / UX：设置分类、搜索、精确参数、键盘操作、短窄窗口、快捷键重绑、座位与载具面板、预设存取与 JSON 校验、天气选择、公告及失败恢复入口。
- SFX / BGM：原生音频节点检测十个频道的实际信号、独立静音、试听和恢复；现有回归覆盖发动机转速与换挡、车外发动机、车型喇叭、雨刮与设备音、碰撞、音乐避让、失焦静音及音频初始化失败。

## 验证说明

全量单测以两个 Worker 运行：105 个文件、1,208 项通过。扩充红岩覆盖后的 WorldOptions 文件另行复验，10 项通过。

浏览器全量基线 156 项全部通过，用时 37 分钟；两项新发现的问题先通过失败用例复现，再修复。在最终 v0.1.63 生产构建上复测公告、预设、座位、设备、音频与红岩 / 沙漠驾驶，共 33 项通过，用时 5.4 分钟。Pages 子路径资源与世界加载另测 1 项通过。类型检查、ESLint、生产构建及 diff 格式检查通过。

目视检查窄屏混音面板、双层座位图、远征车场景和地下车库；页面与仓库中的 v0.1.62 公告均与提交前原文逐字比较通过，新版六条公告在两处一致。构建仍有主脚本超过 500 kB 的既有提示，当前主脚本 gzip 约 390 kB。

音频验证使用浏览器原生信号、时序、状态与资源数量，不代表实车录音或主观听感评测。浏览器自动化使用本机 Chromium / ANGLE Metal；短窄窗口检查不等于移动端驾驶支持。程序化桥梁、地形和车辆物理仍采用开发记录中说明的近似模型。本次检查不能证明所有种子与参数组合均无缺陷。
