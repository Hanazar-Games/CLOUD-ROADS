# v0.3.5 出发、声音与短屏检查

先用失败回归确认更换机场后取消按钮残留，以及座舱画面、地图准备期间失焦仍自动登机的问题。统一清除首次登机意图、待出发请求和按钮状态；失焦、隐藏、页面离开及旋转屏幕同时释放操纵输入。首次加载飞行模块后检查页面可见性与焦点，覆盖事件监听尚未建立的后台状态。资源继续准备，返回后手动选择出发；正在飞行则保持暂停。

首次登机的取消按钮提前至模型与座舱画面阶段。回归先确认按钮此前不可见，再检查取消后加载完成、面板和标题焦点保留，以及手动出发与返回仍可用。地图阶段的回归明确等待真实地图阶段，避免提前出现的按钮让测试误测其他阶段。

原生音频采样复现飞机设置页后台残留 BGM：页面隐藏会停止 GameLoop，飞行混音此前依赖下一帧进入后台。失败场景隐藏 200 毫秒后仍测得约 0.0140 RMS。后台事件现在直接设置混音后台状态，淡出声音并静音主总线；修复后同场景低于 0.00001 RMS，返回后配乐恢复。另回归引擎、风噪、跑道、机械分项、独立 SFX / BGM、暂停、警报、设备恢复和退出释放；声音仍为程序合成，采样检查不等同于主观听感评测。

390 × 450 窗口复现顶部新增机场入口后遮挡驾驶仪表：顶部底边为 172 px，数字与指针仪表顶部分别为 156、134 px。短屏收起品牌行并紧凑排列按钮，保留主要操作与三种仪表。另实查 390 × 844 飞机面板，加载说明和机型选择可见，无横向溢出。

修正两项地面驾驶回归的假设：驻车继续严格检查水平位置不变，允许不足 5 cm 的悬挂垂直沉降；雨天隧道手刹使用与已有制动场景一致的 8 秒停车期限。车型面板矩阵与短屏仪表拆为独立用例，49 种车型矩阵单独设置两分钟期限，避免遍历耗尽后续布局检查时间。车辆物理参数没有因测试失败而改动。

当前公告在页面与 CHANGELOG 中一致；v0.3.4 分别按各文件原文归档，更早历史逐字保留。检查中发现的 v0.3.3 两份历史文案差异保留原状。

验证结果：

- 130 个文件、1,673 项 Vitest 测试通过；首次高并发执行出现耗时用例超时，单进程完整重跑通过。208 项航空 Node 测试通过。
- 全量运行原有 223 个浏览器场景，219 项通过；四项失败分别定位为两项驾驶断言、历史公告比对与短屏遮挡。完成修复、版本归档及新增回归后，41 个受影响的定向场景分批全部通过，覆盖出发取消、后台状态、所有机型与机场、声音、三种仪表、预设和旧公告访问。当前浏览器套件共 228 项。
- 3 项 Pages 子路径回归通过，覆盖脚本、样式、GLB、地形 Worker、真实 Web Audio 渲染、恢复及独立测试音；使用独立端口，保留 4319 预览服务。
- 后续生产音频复测中，本机默认音频输出路径的 AudioContext 虽显示 running，时钟仍停在约 0.006 秒。临时浏览器配置添加 `--disable-audio-output` 后，原生 Web Audio 采样、后台静音与恢复通过；最终音频与 Pages 验证采用这一配置。参数未写入游戏或默认测试配置，本轮没有评测物理设备听感。
- lint、TypeScript / Vite 构建、差异格式与公告原文归档检查通过。

主脚本约 1.90 MB，gzip 620 kB，仍有超过 500 kB 的既有构建提示。本轮未测量跨设备帧率提升；本机状态、截图和日志不进入提交。
