# v0.1.1 检查与修复记录

检查范围：仓库现有的世界生成、道路／桥梁、地形与生物群系、Worker 生命周期、渲染恢复、输入、HUD、控制面板和版本公告。采用代码检查、先失败后修复的回归测试、Chromium 实际渲染与截图检查。没有把尚未实现的车辆、天气或音频系统算作已验证功能。

## 已复现并修复

| 问题 | 复现或影响 | 修复与回归 |
| --- | --- | --- |
| 生物群系地面数据滞后 | 高速横向飞行时，F3 坐标对应的地形高度与显示值曾相差约 333 m | F3 每次刷新同时采样坐标和地面；浏览器逐次用确定性高度与雪线算法核对 |
| 编辑种子时残留移动 | 按住 W，再点击输入框，松键前仍持续飞行 | 非画布控件获得焦点时清空输入；禁止编辑控件／公告接收飞行按键 |
| 飞行组合键触发默认行为 | 原实现仅阻止 Space、F3，Ctrl+D 等组合仍保留浏览器默认动作 | 仅在画布／页面背景处理已定义飞行键并阻止默认行为，保留输入控件及系统修饰键的正常操作 |
| 图形恢复后继续移动 | 按住 W 时丢失 WebGL 上下文，恢复后自动继续飞行 | 上下文丢失时停循环、禁用并清空输入；恢复时再次清空后启用 |
| 鼠标锁定失败无提示 | 请求被拒绝后仍提示双击锁定 | 捕获同步异常、Promise 拒绝及锁定错误事件，提示拖动观察；保持拖动可用 |
| Worker 故障未完全释放 | 超时后线程仍在；同步发送失败留下定时器；启动错误可能被遗忘；部分构造失败未清理前面的线程 | 统一终止故障池、拒绝未完成任务并清除定时器，后续任务返回原始错误；通过 7 项专门的生命周期测试 |
| 地形故障缺少直接恢复入口 | 只有错误文字，用户需要自行重新提交种子 | 添加当前世界重试；运行期构造失败也能显示错误；浏览器注入发送失败后验证完整恢复 |
| 观察跳转使用过期路线 | 路线状态改变与按钮刷新之间，观察方法仍可使用旧数据 | 三种观察方法均检查路线就绪状态，未就绪时保留相机位置 |
| 低高度窗口按钮不可达 | 1024×450 窗口中桥梁按钮下缘约为 539 px | 面板限制高度并支持滚动，增加收起入口；浏览器验证滚动后按钮可点击 |

## UI / UX 检查

- 目视检查 1440×900、1024×450、390×844：控制面板、HUD、标题、版本入口和公告布局；窄窗口检查只代表布局检查，不代表已支持触屏驾驶。
- 增加可见的画布键盘焦点、暂停按钮和清楚的开发版能力说明；默认关闭穿透地形的路线骨架，避免与真实路面混淆。
- 公告采用原生模态对话框；验证 Escape 关闭、焦点返回公告按钮、模态期间飞行按键不移动相机，以及当前／历史版本分区。
- 公告独立于 3D 初始化；模拟 WebGL 不可用时，错误信息、页面重新加载按钮和版本公告仍可用。
- 十次连续换种子后，活动 Worker 数保持不变，线框／路线骨架设置保留，加载完成后分块分配回到 289 个。

## 核心世界与新生物群系复查

- 地表采样使用逻辑世界坐标、道路耦合后的高度与法线；桥跨下方仍使用自然谷底。未发现需要修改生物群系生成公式的新错误。
- 验证种子与采样顺序独立、归一化混合权重、有限颜色、海拔平滑过渡、空间雪线及陡坡露岩。
- 保留同级及混合 LOD 边界属性一致性、道路／地形射线间距、桥梁落点与支撑、10 / 30 / 100 公里非渲染模拟，以及浏览器 30 公里飞行／回放回归。
- 保留资源池和 Worker 生成路径；未引入运行时存档、外部美术资源或未发布行为的兼容层。

## SFX / BGM 检查结论

仓库没有音频文件、音效模块、音乐播放器或 Web Audio 初始化代码，当前页面为静音的世界引擎验证版本。因此不存在可供试听的混音、循环衔接、淡入淡出、音量设置或自动播放权限流程；本次未把这些项目标记为通过，也未临时添加占位音频。界面、README 和公告均明确说明声音尚未实现，仍属于后续 Polish 阶段。

## 验证与边界

- `npm run build`、`npm run lint`、65 项单元测试、18 项 Playwright 测试。
- Apple M5 Pro / ANGLE Metal / 1920×1080，连续飞行 10 秒约 60 FPS，p95 与最大帧间隔均约 16.8 ms，无超过 50 ms 的主线程任务；末帧 289 个活动分块、95 次 draw call。这是单机短时抽测。
- 实际浏览器覆盖 Chromium / ANGLE Metal；其他浏览器、长期压力和真实屏幕阅读器仍需单独验证。
- 森林和雪区当前为地表颜色；无树木、积雪几何或车辆。自由相机允许穿山；远景依赖基础雾，不保证极高空视角完整。
- 构建仍有 Three.js 引起的 500 kB 包体积提示；它不导致构建失败。本次没有为消除提示而进行无关拆包。
