# v0.3.3 音频检查

飞机使用程序合成的四类发动机、风噪、跑道与机械声；没有新增下载资源。连续声部复用一个发动机振荡器、一个循环噪声源，稳定帧不重复创建节点或提交相同参数自动化。驾驶舱隔音仅影响外部声音，音乐和警报独立。

先复现再修复步行时附近 NPC 碰撞不压低音乐、声音按钮无障碍状态写反、窄屏诊断关闭按钮被导航遮挡，以及退出后短音效滤波节点依赖结束回调断开的问题。旧公告按原文归档。

验证结果：

- 130 个文件、1,671 项 Vitest 测试；206 项航空 Node 测试通过。
- 30 项浏览器回归通过，覆盖音频激活、设备恢复、分项静音、独立音乐、暂停与失焦、退出释放、机场登机、12 款机型、飞行操纵、手机与公告。
- 3 项 GitHub Pages 子路径测试通过，覆盖构建资源、飞机模型、地形 Worker、实际音频与设备恢复。
- 原生 OfflineAudioContext 渲染 21 个场景：四类引擎、座舱、滑翔、停车、暂停、组合事件和 12 款配乐。采样均为有限值，测试最大绝对峰值约 0.17；停车关闭引擎、暂停场景输出为零，座舱外部声音 RMS 低于外部机位的 60%。这是这些测试场景的结果，不是任意混音的峰值保证。
- 实查 390 × 780 手机音量界面，无横向溢出，改善浅色面板上百分比的对比度。lint、TypeScript / Vite 构建和差异格式检查通过。

未进行主观耳机听感评测；机型声音为游戏化合成，非实机录音。保留原有主脚本体积提示，未改变公路与飞行资源的拆包方式。本机设置、测试日志与截图不提交。
