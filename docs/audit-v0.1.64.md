# v0.1.64 检查记录

本次发布包含 v0.1.63 之后的自然隧道覆土、匝道与服务区接驳、转向调校、植被细节、性能滑条和分类设置改动，并对 UI / UX、SFX / BGM、驾驶和流式世界进行了回归。

## 问题与修复

| 问题 | 复现与原因 | 修复与验证 |
| --- | --- | --- |
| 静音驾驶音效仍压低音乐 | 将全部音效、发动机或碰撞声静音后，油门 / 碰撞仍参与音乐避让。三种失败用例中，音乐混音系数仍降到约 0.2。 | 仅有效声部参与驾驶音乐避让，全部音效静音时关闭这一影响；检查重新开声与平滑恢复。32 项音频单测通过。 |
| 设置搜索漏掉快捷键修改操作 | 搜索“鸣笛 快捷键”没有结果；搜索只收集带 ID 的按钮，动态快捷键按钮没有 ID。 | 纳入快捷键按钮的无障碍名称和分组文字；浏览器检查搜索、定位、不自动进入绑定、重绑后再次搜索。 |
| 新设置布局的边界问题 | 短窗口隐藏帮助行后仍保留原有网格行数，页脚被挤出；滚动定位可能移动整个弹窗；游戏按键替换会误改固定搜索快捷键提示。 | 修正短屏网格行数及弹窗滚动边界，固定提示不参与游戏绑定替换；检查 390×450、390×844、1440×900、减少动态效果、键盘焦点和分类滚动恢复。 |
| 隧道长度帮助过时 | 探索说明仍写单座最长 5 公里，与连续隧道实现不符。 | 改为按天然山势连续生成，无固定长度上限，标牌显示已探明长度。同步实际性能参数与预设格式说明。 |

## 新功能与场景检查

- 地形与道路：山顶和地下表面分层、深埋隧道上方天然植被、真实洞口净空、曲线与 40% 坡度双幅隧道、挖孔地块回收复用；桥梁、路肩、互通、服务区接驳高差及护栏开口使用几何和碰撞回归检查。
- 驾驶与模型：渐进 / 即时转向、回正和反向响应、摩托车倾斜与车把前叉联动、自动驾驶前视、漂移、护栏擦碰、长车、上下车、乘客权限、设备与座位图；全车队尺寸、部件预算及资源释放继续通过已有测试。
- 植被与性能：数量稳定抽稀及恢复、近中远景模型、月球 / 火星岩块色调、更新队列优先级、卸载防复活、设施空间索引与矩阵复用。浏览器检查改植被不生成新地块、不移动玩家、不重设画布；连续渲染比例输入合并更新，图形恢复保留选择。
- UI / UX：12 个分类、折叠、搜索、禁用参数、精确输入、数值校验、天气卡片、快捷键重绑、预设 JSON 与本机启动恢复、移动尺寸布局、故障入口及公告。保留原有 427 个静态控件 ID，最终 469 个 ID 无重复。
- SFX / BGM：原生 AudioContext 与分析器检查十个音乐频道、快速调台、独立静音、试听、暂停 / 公告 / 失焦恢复、静音预设不创建音频图，以及初始化和恢复失败。回归发动机负载、转速和换挡、车外发动机、车型喇叭、碰撞及设备音。

## 验证结果

- 全量单测：108 个文件、1,249 项通过，两个 Worker，约 127 秒。
- 浏览器全量基线：167 项，161 项通过，6 项失败，约 38.8 分钟。逐项确认：两处旧设置定位未适配新分组，一处乘客权限测试误将 7 cm 悬挂回落判为移动，三处加速 / 手刹测试使用了过短的统一等待时间。
- 测试修正保留速度目标、最终停稳、水平位置和驾驶权限断言；护栏测试增加持续减速检查。未修改车辆制动力以迎合超时。最终 v0.1.64 生产构建复验全部失败场景和设置、预设、音频、驾驶、天气、公告，共 59 项全部通过，约 8.9 分钟，其中包含两项新浏览器回归。
- Pages 项目子路径的脚本、样式、Worker 与世界加载另测 1 项通过，约 7.3 秒；本机 4320 预览已提供最终构建。
- TypeScript、ESLint、生产构建及 diff 格式检查通过。页面与 CHANGELOG 的七条新版公告一致；两处 v0.1.63 历史公告与提交前原文逐字比较一致，package 与 lockfile 版本一致。
- 已目视检查设置短屏 / 桌面、声音混音、车内场景、植被山路及新版公告。临时测试配置和开发服务器已清理，运行时设置与截图不进入提交。

音频验证基于原生信号、时序、状态与资源数量，不代表主观听感评测或实车录音。测试使用本机 Chromium / ANGLE Metal；小窗口可用性不等于移动端驾驶支持。构建保留主脚本超过 500 kB 的提示，gzip 约 394 kB。程序化几何、车辆物理与局部灯光仍有开发记录中的近似和限制，不能据此保证所有随机种子与参数组合都无缺陷。
