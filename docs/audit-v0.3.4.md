# v0.3.4 加载与混音检查

机坪和飞行模式交接同一个标准化飞机 Group，不克隆或缓存其他机型；返回时复原机位变换、可见性和起落架。加载取消、更换机型与世界销毁保持资源所有权明确。浏览器连续两次登机、返回 Su-30，模型请求总计一次；Pages 子路径首次登机 A380 也只请求一次。减少的是重复下载、解析与模型资源创建，未测量跨设备帧率提升。

加载状态移至设置面板顶部，模型等待不显示虚构下载百分比，画面与地图按实际准备步骤推进；地图仍等待九个附近地块上传和远景首次绘制。新增取消自动出发，继续准备但不推进物理，取消后键盘焦点回到面板标题。稳定等待时约 10 Hz 检查出发条件，交互变更及时检查。390 × 844 手机实查进度和取消按钮完整可见，无横向溢出；机场说明和返航目标的海拔改为整数米。

先用失败测试复现分项音量不能影响已播放短音效、快速切换配乐未计入淡出节点的问题。风噪、跑道和机械短音效现在通过可实时调节的总线；前两者经过座舱隔音，机械与警报保持独立。活动和淡出声部合计遵守预算：音乐 36、普通效果 44、警报 48，保留两个持续源。达到预算先回收旧的淡出声部，退出与设备重建释放全部连接。

验证结果：

- 130 个文件、1,673 项 Vitest 测试及 208 项航空 Node 测试通过。
- 30 项不同的浏览器回归通过，覆盖反复登机、全部机型和机场、操纵与视角、取消出发、加载失败、图形中断、手机布局、真实音频、地面预加载和设备恢复；焦点修正后重跑四项飞行预加载回归。
- 3 项 Pages 子路径回归通过，覆盖构建资源、GLB、地形 Worker、音频输出和恢复；使用独立测试端口，保留原预览服务。
- 原生 OfflineAudioContext 渲染机械、离地气流和接地三组音效，中途将对应分项音量设为零；静音后采样 RMS 均低于静音前的 0.003%，采样为有限值。这是测试场景的结果，未进行主观耳机听感评测。
- 同一模拟时刻连续切换 100 次配乐主题，持续源与已连接音乐源合计不超过 38 个；停止及销毁后全部断开。模型所有权、陈旧机型拒收和恰好一次释放有回归覆盖。
- lint、TypeScript / Vite 构建及差异格式检查通过。当前公告与 CHANGELOG 一致；两个文件中的 v0.3.3 公告分别按原文归档。

保留原有主脚本超过 500 kB 的构建提示。没有新增下载音频或改变现有飞行物理；测试日志、截图及本机运行状态不提交。
