# v0.1.66 检查记录

本次发布纳入此前尚未提交的五语界面、信号路口、交规提醒、音频恢复与诊断日志，以及车辆、座舱、互通和加载预算改进。检查覆盖 UI / UX、SFX / BGM、物理、世界生成与故障恢复，基于本机 Chromium / ANGLE Metal；自动化通过不等同于所有随机种子和设备绝对无缺陷。

## 问题与修复

| 问题 | 复现证据 | 修复与验证 |
| --- | --- | --- |
| 交规提示在暂停时反复更新，下车后仍残留 | 超速提示出现后打开设置，500 ms 内记录到 30 次文字节点变化；原逻辑把暂停与离开驾驶席合并处理，暂停也会清掉累计超速时间。 | 区分驾驶资格与暂停时间，暂停保留计时，离座清除当前提醒；只在内容变化时写入 DOM。单测验证计时，英文界面浏览器回归验证暂停时 0 次改写、停车下车后隐藏。 |
| 缩小窗口后当前设置分类滚出可见区域 | 从桌面宽度切换到 390 × 450 后，内容仍是交通分类，分类导航却停留在最左端。 | 窗口尺寸变化时重新定位当前分类；核对英、西、韩、日四种界面，关闭按钮和正文可用，分类保持可见。几何断言允许浏览器滚动取整造成的半像素误差。 |
| 多语言异常提示混排 | 音频初始化失败在英文中出现 `Current浏览器无法On音频`；预设校验、按键存储及道路验证等提示缺少完整词条。 | 补齐四种外语的完整错误与恢复说明；单测覆盖异常词条，浏览器注入音频创建失败并导入非法 JSON，验证四语言提示、设置保留和声音重建。 |
| 日志空状态不翻译，状态文字重复改写 | 整个日志列表被排除翻译，英文下仍显示“当前筛选下没有日志”。状态比较使用翻译后的文字，导致不断写回中文。 | 仅原始日志行保留原文，空状态正常翻译；按原始文本判断状态变化。浏览器检查空状态和静止状态 600 ms 内 0 次文字改写。 |
| 参数说明出现重复 ID 与重复关联 | 打开设置后出现 9 个重复 ID，包括转向、最大坡度、雾能见度、渲染比例与视距说明；滑条及数值框重复引用同一 ID。 | 自动生成说明使用独立的 `-parameter-help` ID，同时保留原有说明；浏览器检查整页 ID 无重复，所有设置说明引用存在且不重复。 |
| 旧回归断言未同步新选项 | 五项基线失败仍期待旧音频错误文字、旧视距索引、地图细节控制纹理和旧分类列表。 | 按实际新语义更新断言；纹理测试增加独立控制与换世界保留检查。全部失败场景在最终生产构建复测通过。 |
